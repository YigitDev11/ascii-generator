This is an ASCII Generator script written by @YigitDev11. All the dependendencies are included in pyproject.toml. All you need is to run these commands in the right order:

1 - "uv venv" or "python -m venv .venv"
2 - "uv sync" or "pip install -r pyproject.toml"
3 - "uv run main.py" or "python main.py"

If you are using uv you can use uv commands but if you are not using uv you can use pip commands instead. It does not effect the tool's runtime.

Thank you for using our tool!
